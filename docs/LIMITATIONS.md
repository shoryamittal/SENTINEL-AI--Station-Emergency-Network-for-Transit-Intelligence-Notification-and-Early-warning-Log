# Limitations and scope

## Proven in the current prototype

- YOLO person detection and relative 4×6 spatial occupancy
- adaptive L/A/R signals with scenario/severity logic
- local-first SQLite incident persistence and restart recovery
- local warning, durable acknowledgement, and store-and-forward sync
- immutable event replay, idempotency qualification, and stale-output protection
- REALITY and SIMULATION input modes through the same intelligence path

## Not yet claimed

- exact calibrated people/m² density
- railway-certified thresholds or formal railway operating procedures
- guaranteed stampede prediction or prevention
- full directional Flow Conflict/counterflow tracking
- production national railway backend or cloud deployment
- production IAM, RBAC, TLS, secret management, or operator identity system
- hundreds-camera load benchmark
- formal railway operational certification

Production deployment would require operator-controlled infrastructure, site calibration, security controls, monitoring, retention policy, integration validation, and governance by the deploying operator.
